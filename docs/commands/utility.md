# ⚙️ Utility Module
General purpose tools for information gathering and server management.

## Commands
- `/help`: Opens the interactive Command Atlas.
- `/ping` (p): Checks bot latency and heartbeat.
- `/userinfo` (ui): Displays a detailed member dossier.
- `/serverinfo` (si): Displays a comprehensive guild snapshot.
- `/avatar` (av): Views a user's high-resolution avatar.
- `/banner`: Views a user's profile banner.

## Pro Tips
Most utility commands support shorthand prefix aliases (e.g., `!p` for ping, `!si` for serverinfo).

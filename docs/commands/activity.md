# 📊 Activity & Telemetry Module
StatBot-grade server growth charts, user active donut splits, and dynamic chat leaderboards.

## Commands
- `/activity user`: Displays your cyber glassmorphic profile card with your Top Channels Donut Chart and overall dossier.
- `/activity server growth`: Renders a premium Skia-Canvas joins/leaves attrition chart for the last 7 days.
- `/activity server hotspots`: Lists the Top 5 active channels and triggers a Dead Channels audit to find idle rooms.
- `/activity leaderboard`: An interactive paginated leaderboard filterable by category (messages, voice, media, reactions) and timeframe (today, weekly, monthly, all-time).

## Pro Tips
- The **/activity user** command draws a real-time custom canvas chart of where you chat the most!
- Click the dropdown select menus in **/activity leaderboard** to filter metrics on the fly instantly!

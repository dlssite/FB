# 🛡️ Automod Module
Automated server defense against spam, raids, and malicious content.

## Features
- **Anti-Spam**: Prevents message flooding using a stateful Leaky Bucket algorithm.
- **Anti-Invite**: Automatically deletes unauthorized Discord invites.
- **Anti-Link**: Blocks suspicious or unauthorized URLs.
- **Anti-Nuke**: Protects against rogue staff deleting channels or mass-banning.

## Configuration
Use `/automod config` to manage:
- **Exemptions**: Whitelist roles or channels from protection.
- **Log Channel**: Set where violations are reported.
- **Master Toggle**: Enable/Disable the entire module or specific protections.

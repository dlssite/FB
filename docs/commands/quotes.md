# 📜 Advanced Quote System

The Quote System immortalizes memorable messages by generating beautiful, high-fidelity canvas images in multiple iconic social media styles.

## 🖼️ Quoting Commands

### `/quote <message_id> [style]`
Generates a stunning visual quote card of the target message.
- **Prefix Support**: You can also reply to any message with `$quote [style]`.
- **Supported Styles**:
  - `classic` (Elegant, minimalist dark card)
  - `twitter` (Authentic tweet simulation)
  - `reddit` (Classic comment thread aesthetic)

# 🔞 Advanced NSFW Browser

The NSFW Browser provides an interactive, multi-provider media explorer with personal Vaults (Favorites) and strict age-restricted channel gating.

## 🔍 Browsing Commands

### `/nsfw`
Spawns the interactive **Media Explorer Panel**.
- **Requirements**: Can only be executed inside age-restricted (NSFW) channels.
- **Features**:
  - **Multi-Provider Search**: Browse high-quality curated feeds.
  - **Personal Vault**: Save your favorite media directly to your private collection.
  - **Interactive Controls**: Seamless pagination and instant category switching.

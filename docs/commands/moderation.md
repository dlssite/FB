# 🔨 Moderation Module
The Moderation module provides high-performance tools for server staff to maintain order and security.

## Commands
- `/ban` (b): Permanently bans a user from the server.
- `/kick` (k): Removes a user from the server.
- `/warn` (w): Issues a formal warning to a user.
- `/warnings` (warns): Views a member's warning history.
- `/unwarn` [id]: Removes a specific warning case.
- `/clearwarnings`: Wipes all warnings for a member.
- `/timeout` (t, m): Native Discord silencer (e.g. 10m, 1h).
- `/untimeout` (um): Restores member permissions.
- `/modactions` (mc): Views the server audit log.

## Staff Flags
You can use the `?r` flag in prefix commands to add a reason instantly.
*Example:* `!ban @user ?r Breaking Rule 1`

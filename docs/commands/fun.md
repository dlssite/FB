# 🎉 Fun & Games Module
Premium entertainment, trivia games, jokes, and interactive math solvers.

## Commands
- `/fun joke` (`!joke`): Tells a random programming or dad joke.
- `/fun riddle` (`!riddle`): Get a riddle with an interactive answer reveal button.
- `/fun trivia` (`!trivia`): Play an interactive multiple-choice trivia game.
- `/fun math` (`!math`): Safely evaluates mathematical expressions (e.g. `2 + 2 * sqrt(16)`).
- `/fun meme` (`!meme`): Fetches a random meme from Reddit.
- `/fun roast` (`!roast`): Delivers a playful roast to a designated user.
- `/fun coinflip` (`!coinflip`, `!cf`): Flips a coin for quick decision-making.
- `/fun 8ball` (`!8ball`): Ask a question and let the magic 8-ball decide your fate.
- `/fun fact` (`!fact`): Shares an interesting, random fact.

## Pro Tips
- The **Riddle** and **Trivia** commands use advanced interactive buttons. 
- Trivia answers are secured to the user who started the game via Redis so other users cannot interrupt!

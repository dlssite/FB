# 🏪 Hyper-Shop (Economy Engine)

The Hyper-Shop is a unified marketplace and inventory system featuring dynamic pricing, item degradation, and player-to-player trading.

## 🛍️ Marketplace Commands

### `/shop browse`
Opens the interactive **Global Marketplace Center** to browse and purchase items across multiple specialized departments.
- **Prefix**: `$shop`

### `/inventory`
Opens your personal backpack to view acquired assets, check item condition, and use functional items (e.g., Deploying Buildings, Opening Crates).
- **Prefix**: `$inv` or `$inventory`

### `/trade <user>`
Initiates a secure, interactive player-to-player trade session to exchange Embers and items.
- **Prefix**: `$trade <user>`

## 🛠️ Administrative Commands

### `/admin set-news-channel`
Configures the broadcast channel for automated Marketplace News (Big Sales, New Templates, Auction Alerts).
- **Permission**: `ManageGuild`

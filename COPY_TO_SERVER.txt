IMMEDIATE STEPS ON SERVER
───────────────────────────────────────────────────────────────────────────────

1. Make scripts executable:
   $ chmod +x deploy-single.sh troubleshoot.sh

2. Diagnose issues (optional but recommended):
   $ ./troubleshoot.sh

3. Deploy Kai to test:
   $ ./deploy-single.sh kai

4. Check if it works:
   $ pm2 logs flameborn-kai

   Expected: Bot starts with NO DATABASE_URL error ✅


IF WORKING, DEPLOY OTHERS
───────────────────────────────────────────────────────────────────────────────

$ ./deploy-single.sh ember
$ ./deploy-single.sh saphy
$ ./deploy-single.sh liber

Or all at once:

$ ./deploy.sh


VERIFY ALL RUNNING
───────────────────────────────────────────────────────────────────────────────

$ pm2 status          # Check all bots online
$ pm2 logs            # View all logs


MAKE PERSISTENT (Optional)
───────────────────────────────────────────────────────────────────────────────

$ pm2 save            # Save PM2 config
$ pm2 startup         # Auto-restart on server reboot
